# MedicalDirector (medical-director)

MedicalDirector is an Australian clinical and practice-management software provider, owned by Telstra Health, that has served general practices, specialists, and day hospitals across Australia for more than 25 years. Alongside Best Practice, it is one half of the dominant Australian GP-software duopoly. Its programmatic surface is delivered through Telstra Health Smart API+, a FHIR-native integration gateway for approved technology partners integrating with MedicalDirector Helix (and MedicalDirector Clinical on a case-by-case basis). Smart API+ is publicly announced and described, but it is a gated, partner-onboarded API — there is no self-serve public developer portal, and no FHIR CapabilityStatement or OpenAPI is published anonymously.

## APIs

### Telstra Health Smart API+

FHIR-native integration gateway from Telstra Health providing a single, standardized interface for approved technology partners to exchange data with MedicalDirector Helix cloud general-practice patient-management software (and, case-by-case, MedicalDirector Clinical). Marketed as a build-once gateway that removes the need for bespoke, platform-specific integrations across Telstra Health's primary-care ecosystem. Access is gated behind a partner agreement; no public FHIR CapabilityStatement, metadata endpoint, or OpenAPI is served anonymously, and the specific FHIR version and auth scheme are not disclosed on public pages.

- **Human URL:** [https://www.telstrahealth.com/products/smart-api/](https://www.telstrahealth.com/products/smart-api/)
